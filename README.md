# Privi AI marketing site

This public repository contains only the static marketing page for `getprivi.ai`. Its waitlist form is a disabled placeholder and collects no email addresses. It has no analytics, externally loaded fonts, or app code. The draft's three SVG illustrations and locally hosted Newsreader, Inter and IBM Plex Mono fonts are included, along with their OFL license texts.

The editable source of truth is the private Privi repository's `website/dist/` directory. Copy those files here before publishing changes. GitHub Pages serves this repository's `main` branch from its root.
